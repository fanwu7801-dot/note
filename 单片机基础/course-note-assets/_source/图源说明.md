# 图源说明

概念图保存在每课目录的 concept-*.json、concepts.drawio 中。
带连线图也在 concepts.drawio 中，均可用 draw.io 编辑。
PNG 适合阅读，SVG 适合放大。课件截图 source-p*.png 的页码见笔记。

redraw.py 保存专项波形、布局和带连线图的重绘逻辑。
数值为教学示例，未导入实际示波器或开发板测量数据。

本机使用 diagramry 技能的 Python 运行时，依赖 matplotlib、numpy、
schemdraw，并使用 Microsoft YaHei 字体。脚本从用户目录下读取
.codex/skills/diagramry/scripts/render_diagram.py。
在其他机器使用时需调整该依赖路径和字体。

运行 redraw.py 只重绘专项图片、JSON 与 specials.drawio，
不覆盖 Markdown 笔记、课件 PDF 或 concept-*.json。
若手动修改了图片，应先保存副本，再决定是否重绘。

## 深入学习配图

deeper_diagrams.py 生成 deep/各课编号/ 下的新增深入配图，
涵盖建立误差、混叠、中心对齐、参数提交、缓存、时钟漂移与任务响应。
运行它不会重写 Markdown、原有课件或基础图。

曲线采用明确模型计算，提供 PNG 与 SVG；结构图另提供 JSON
及 deep.drawio，可在 draw.io 中编辑。图旁的“怎么看”说明假设和读法。
这些图均为教学推导，不能当作板级实测记录。

## 深入机制补图：72幅

extended_diagrams.py 在 extended/各课编号/ 下生成本批图，
不重建 Markdown，也不覆盖 deep/ 与原有基础图。
manifest.json 记录每图对应的课号、深入小节、标题与读法。

17篇均补图；定时器输出与FreeRTOS各6幅，其余15篇各4幅。
图形包含位布局、地址译码、读写时间线、竞争窗口、分支流程和公式曲线。
每图提供 PNG、SVG；结构图还提供同名 JSON 和分课 extended.drawio。
曲线与布局的可编辑数值、标签、公式保存在 Python 图源中。

正文将补图放在对应深入小节旁，每图附单位、假设、读法及SVG链接。
结构图的分支和连线用于说明教学机制，不表示已核实的具体板卡布线。
容量图区块按比例显示，狭窄区块使用外部标注，不能把图宽当作地址值。
透明结构图统一加白底，保证深色阅读界面中的文字对比度。
