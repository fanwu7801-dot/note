# STIM 标定与页面管理

## STIM 到底是什么

STIM 是 **Stimulus，刺激/激励**。它允许 XCP Master 把外部产生的变量值送入 ECU，并在指定事件点让控制算法使用这些值。

DAQ 是 ECU 把内部变量送出去；STIM 是工具把外部变量送进来。两者都使用同步数据对象和事件配置，但方向相反。

```text
DAQ：应用变量 -> XCP Slave -> DTO -> Master
STIM：Master -> DTO -> XCP Slave -> 应用算法
```

## STIM：从工具向 ECU 注入同步数据

STIM 与 DAQ 的组织方式相似，但方向相反。Master 按事件周期发送 DTO，ECU 在控制任务的同步点接收，并把数据提供给算法使用。

```text
Master 计算或发送输入
        ↓
STIM DTO
        ↓
ECU 接收缓冲区
        ↓
事件点更新数据快照
        ↓
控制算法读取
```

STIM 常用于 bypass、快速原型和外部算法验证。实现时要定义数据未及时到达、计数器不连续和超时后的降级值。

## STIM 的典型应用

### 外部算法旁路

ECU 保留采集和执行框架，工具或外部旁路设备计算新的控制量，并通过 STIM 注入。这样可以在不重新刷写完整控制算法的情况下比较新旧算法。

### 传感器替代

测试工具把模拟的温度、压力或车速送入 ECU，验证故障处理和控制逻辑。此时必须确认 STIM 数据是否覆盖真实传感器输入，以及安全监控是否仍然有效。

### 自动化测试

测试脚本按事件周期生成可重复输入，并同时用 DAQ 记录输出，形成“刺激 -> 响应”的闭环数据。

## STIM 数据何时生效

建议把“收到 CAN 帧”和“算法使用数据”分成两个时刻：

```text
CAN 接收中断/DMA
        ↓
写入接收缓冲区
        ↓
事件点校验并切换快照
        ↓
控制算法读取稳定快照
```

这样可以避免控制任务读到半帧或半更新数据。若 DTO 到达晚于事件点，本周期可以继续使用上一份有效值，同时增加超时或过期计数。

## STIM 的有效性策略

至少定义以下状态：

| 状态 | 含义 | 算法处理 |
| --- | --- | --- |
| VALID | 本周期数据完整且序号正确 | 使用 STIM 值 |
| STALE | 数据未更新但仍在允许窗口 | 使用上一份值或限幅值 |
| TIMEOUT | 超过最大等待时间 | 切回真实输入或安全值 |
| INVALID | 长度、范围或校验错误 | 丢弃本帧并记录错误 |

状态属于模块 `ctx`，对算法公开的是带有效性和时间戳的 `data` 快照。

## CAL 与 PAG

- **CAL**：标定资源，允许读取或修改参数。
- **PAG**：页面管理资源，用于工作页和参考页的选择、切换和保存。

常见概念：

```text
参考页（Reference Page）：当前基准参数
工作页（Working Page）：当前 ECU 实际使用、可在线修改的参数
```

具体页面是否位于 RAM、Flash 或外部存储器，由 ECU 的内存布局和实现决定。

## RAM 标定和 Flash 保存的区别

```text
连接工具
  ↓
读取当前参数
  ↓
修改工作页 RAM
  ↓
观察测量结果
  ↓
确认参数
  ↓
执行保存/编程流程
```

RAM 修改通常掉电丢失；Flash 保存需要考虑擦写次数、掉电中断、版本号、完整性校验和回滚。XCP 命令返回正响应只表示协议层接受，不等同于参数已经安全持久化。

## 参数边界

在线标定接口至少应检查：

- 地址所属内存段；
- 参数长度和对齐；
- 最小值、最大值和枚举合法性；
- 当前 ECU 状态是否允许修改；
- 多字节参数是否需要原子切换；
- 修改后是否需要重新计算校验或通知应用。

## cfg / ctx / data / ops 映射

| 分类 | 示例 |
| --- | --- |
| `cfg` | 页地址、页大小、参数范围、Flash 块配置 |
| `ctx` | 当前工作页、保存状态、擦写进度、STIM 超时计数 |
| `data` | 当前参数快照、保存结果、STIM 数据有效标志 |
| `ops` | 选择页面、切换页面、保存参数、接收 STIM |

外部工具应通过 XCP 操作请求页面切换，不能直接修改模块内部的保存状态或擦写进度。

## 安全提醒

带写权限的 XCP 接口应在开发环境和量产环境采用不同策略。Seed & Key、内存访问白名单、调试口控制和编程权限必须由项目安全要求定义，不能为了方便而开放全部地址空间。

## 参数修改的事务性

如果一个标定参数由多个字段组成，例如比例、限幅和使能开关，逐字段写入可能让算法短暂看到不一致组合。可以采用影子区、版本号或提交标志：工具先写完整副本，校验通过后再一次性切换活动版本。

## DAQ 与 STIM 的对照练习

假设 `TargetTorque` 是控制算法的输入，`ActualTorque` 是算法输出：

```text
STIM：Master 周期发送 TargetTorque
算法：在 10 ms 事件点读取 TargetTorque
DAQ：ECU 周期发送 ActualTorque
Master：对齐两条曲线分析响应
```

练习时分别记录数据的生产者、消费者、时间点、缓存位置和失效后的替代值，这比只背“STIM 是激励”更接近工程实现。
