# 练习题与检查清单

## 基础题

1. XCP Master 和 Slave 分别位于哪里？
2. CTO 和 DTO 的用途有什么区别？
3. A2L 为什么不能被 XCP 协议本身替代？
4. DAQ 为什么比周期轮询更适合观察控制任务的动态行为？
5. STIM 与 DAQ 的数据方向分别是什么？

### 参考答案

1. Master 是标定或测试工具，Slave 是 ECU 内的 XCP 协议实现。
2. CTO 承载命令、响应和事件；DTO 承载 DAQ/STIM 同步数据。
3. XCP 负责访问和传输，A2L 负责地址、类型、换算和连接描述。
4. DAQ 可以在 ECU 事件点采样，并减少每个变量单独请求的往返。
5. DAQ 通常是 ECU 到 Master，STIM 通常是 Master 到 ECU。

## 报文题

给定教学配置：命令 CAN ID 为 `0x600`，响应/DAQ CAN ID 为 `0x650`，请回答：

1. 哪个方向的帧用于发送命令？
2. 如何判断一帧是正响应、错误响应还是 DAQ DTO？
3. 为什么不能只看 CAN ID 就确定变量含义？
4. 如果 DTO 周期不是预期的 10 ms，应检查哪些模块？

### 参考答案

1. 命令由 Master 发往命令接收 ID 对应的 ECU 方向。
2. 先根据 PID/消息类型判断，再结合命令上下文区分 RES、ERR 和 DAQ DTO。
3. CAN ID 只说明传输路由，变量含义还要由 PID、ODT 和 A2L 共同解释。
4. 检查 Event Channel 触发点、控制任务周期、ODT 配置、发送队列、CAN 仲裁和丢帧统计。

## 内存访问题

某变量地址为 `0x20001000`，长度为 2 字节，原始值为 `1500`，换算系数为 `0.1`，偏移为 `-40`。

1. 物理值是多少？
2. 读取流程中为什么要先设置 MTA？
3. 如果地址越界，Slave 应如何处理？
4. 如果变量位于 Flash，为什么不能简单按 RAM 写入处理？

### 参考答案

1. `1500 × 0.1 - 40 = 110`，单位取决于 A2L 定义。
2. MTA 保存后续上传或下载的目标地址，使命令可以分阶段传输。
3. Slave 应拒绝访问并返回内存错误，不能读写越界地址。
4. Flash 通常需要擦除、对齐、校验、掉电保护和寿命管理。

## DAQ 设计题

要在 10 ms 任务中采集车速、转速、电压和状态：

1. 如何组织 DAQ List、ODT 和 ODT Entry？
2. 变量采样点应放在哪里？
3. 如何评估 DTO 长度和 CAN 带宽？
4. 任务超时或发送队列满时，数据应如何标记或降级？

### 参考答案

1. 可以按 10 ms 事件建立一个 DAQ List，再按 DTO 长度拆成一个或多个 ODT。
2. 采样点应靠近变量更新完成的位置，并避免读取半更新数据。
3. 计算事件频率、每个 DTO 长度和总线帧开销，再叠加其他报文评估利用率。
4. 记录丢帧/溢出统计，按策略丢弃样本、发送事件或降低采集配置。

## 自测标准

达到入门目标的标准是：你能够在不依赖工具自动提示的情况下，解释一组 XCP 抓包中“连接、设置地址、读取变量、配置 DAQ、启动采集”的逻辑，并能指出每个数据字节的协议含义和 A2L 来源。

## 进阶自测

达到进阶目标还应能够：

- 画出一个变量从应用任务到 DAQ DTO 的调用链。
- 说明 STIM 数据迟到时算法使用哪一份值。
- 指出一个 A2L 对象引用的换算、布局和访问属性。
- 设计一次不写 Flash 的断线、超时和队列溢出测试。
- 解释为什么“UPLOAD 回读正确”仍不足以证明控制功能正确。
